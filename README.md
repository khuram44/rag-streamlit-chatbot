# 📄 RAG Document Chatbot

A simple, fully functional **Retrieval-Augmented Generation (RAG)** chatbot.
Upload your own PDF or TXT documents, ask questions in plain language, and
get answers grounded strictly in what those documents say — with sources.

## Features

- Upload multiple PDF and/or TXT files at once
- Automatic text extraction, chunking, and embedding
- Local vector search (FAISS) — no paid database required
- Answers generated by the Groq API, using only your documents
- Clear "not found in documents" response instead of guessing
- Source citations (file name + page number) for every answer
- Session-specific chat history, clear chat, and reset knowledge base
- Friendly error handling for missing keys, bad files, scanned PDFs, etc.

## Architecture

```
Uploaded Documents
        ↓
Text Extraction (pypdf / plain text)
        ↓
Text Chunking (overlapping chunks)
        ↓
Hugging Face Embeddings (all-MiniLM-L6-v2)
        ↓
FAISS Vector Database
        ↓
Relevant Chunk Retrieval (similarity search)
        ↓
Groq LLM (answer generation, grounded in retrieved chunks)
        ↓
Answer + Sources shown in Streamlit chat
```

## Technologies

- Python 3
- Streamlit — web interface
- Groq API (official `groq` SDK) — large language model
- Sentence Transformers (`all-MiniLM-L6-v2`) — embeddings
- FAISS (`faiss-cpu`) — local vector database
- pypdf — PDF text extraction

## Local Setup

```bash
python -m venv venv

# Activate the environment
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

Create a file at `.streamlit/secrets.toml` (this file is git-ignored and
must never be committed):

```toml
GROQ_API_KEY = "your-real-groq-api-key"
```

Then run:

```bash
streamlit run app.py
```

## Streamlit Community Cloud Deployment

1. Push this project to a GitHub repository.
2. Go to [streamlit.io](https://streamlit.io) → Community Cloud → **Create app**.
3. Select your repository, branch, and `app.py` as the main file.
4. Open **Advanced settings → Secrets** and add:
   ```toml
   GROQ_API_KEY = "your-real-groq-api-key"
   ```
5. Click **Deploy**.

## Secret Configuration

The app looks for `GROQ_API_KEY` in this order:

1. `st.secrets["GROQ_API_KEY"]` (Streamlit Cloud or local `secrets.toml`)
2. `os.getenv("GROQ_API_KEY")` (environment variable — used in Colab/terminal)

**⚠️ Security warning:** Never write your API key directly into `app.py`,
`requirements.txt`, `README.md`, a Colab notebook, or any file committed to
a public GitHub repository. Only store it in Secrets or an environment
variable.

## Known Limitations

- Scanned/image-only PDFs are not supported (no OCR included)
- Free Streamlit Community Cloud apps sleep when idle and lose session
  data on restart
- The vector database is rebuilt each session (no permanent persistence)
- Not intended for highly sensitive documents on a public app
